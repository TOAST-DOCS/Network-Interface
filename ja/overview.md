## Network > Network Interface > 概要 { #network-network-interface-overview }

NHN Cloudはネットワークインターフェイス機能を提供します。

ネットワークインターフェイスは仮想ネットワークカードを表すVPCの論理的ネットワーク要素です。
次のプロパティを含めることができます。

* VPCのアドレス範囲にあるプライベートIP(Private IP)アドレス
* Floating IPアドレス
* セキュリティ設定
* スプーフィング防止設定
* 1つ以上のセキュリティグループ
* 仮想IP
* 接続された装置
* 名前

ネットワークインターフェイス機能で次の作業を行うことができます。

* ネットワークインターフェイスのVPC、subnet、Floating ip、接続されたセキュリティグループ、接続された装置、状態などをひと目で確認できます。
* ネットワークインターフェイスを他のサブネットのIP帯域に変更したり、他のセキュリティグループを使用するように設定できます。
* セキュリティ、セキュリティグループ、スプーフィング防止、追加許可アドレスを設定して、柔軟にセキュリティを管理できます。
* 仮想IPとして使用するIPをあらかじめ確保し、システムリソースとして活用できます。
