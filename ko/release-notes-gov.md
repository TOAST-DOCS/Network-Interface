## Network > Network Interface > 릴리스 노트

**Network > Network Interface > 릴리스 노트**

## 2026. 06. 02.

### 신규 기능 추가

* '소스/대상 확인' 기능의 이름 변경('스푸핑 방지') 및 설정 위치 이동
    * "소스/대상 확인" 기능의 이름을 "스푸핑 방지"로 변경하고 네트워크 인터페이스 생성, 변경 화면에서 설정하도록 위치를 이동하였습니다.
* 스푸핑 방지 '추가 허용 주소' 설정 기능 추가
    * 스푸핑 방지 사용 중 특정 주소만 스푸핑을 허용하는 "추가 허용 주소" 설정 기능이 추가되었습니다.
    * [Network Interface 콘솔 사용 가이드](/Network/Network%20Interface/ko/console-guide/)를 참고하세요.

## 2022. 04. 05.

### 신규 기능 추가

* 이중화를 위한 가상 IP 생성 기능 추가
    * 가상 IP로 사용할 IP를 선점하고, 라우팅 테이블에서 해당 IP로의 라우트를 추가할 수 있습니다.
* 네트워크 인터페이스 보안 설정 해제 기능 추가
    * 인스턴스를 게이트웨이/방화벽 등의 용도로 사용할 수 있도록 네트워크 인터페이스의 보안 설정을 해제하는 기능이 추가되었습니다.
